## Status

There is no working software yet. The design is under review in
[docs/superpowers/specs/2026-10-02-chambers-design.md](docs/superpowers/specs/2026-10-02-chambers-design.md),
which says what Chambers owns, what it will never be, and the questions still
open.

Read that before opening an issue, so a disagreement lands on the design rather
than on an implementation nobody has written.
